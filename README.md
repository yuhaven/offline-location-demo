# 极端定位 Demo（无网络 · 无卫星）

给人用的极简一页：**相对起点的位移 + 朝向**，一键生成求救短句。

- HTTPS：https://yuhaven.github.io/offline-location-demo/
- 仓库：https://github.com/yuhaven/offline-location-demo

## 人怎么用（两步）

1. 手机打开链接 → 点「开始定位」并允许传感器  
2. 走动看「离起点 / 朝向」→ 需要时点「生成求救短句」

可加到主屏（PWA）。首次需联网加载；之后飞行模式仍可用已缓存页面 + 本机传感器。

## 做得到 / 做不到

- ✅ 无网无星持续给出相对位移与朝向、本地 SOS  
- ❌ 不承诺绝对经纬度 / 厘米级 / 救援绝对坐标

## 交付成功标准

普通人手机两步跑通；顶部状态自动显示传感器是否可用。
